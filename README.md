Este material acompanha os quatro encontros do módulo 1. Tudo aqui é fictício e pode ser colado em qualquer assistente de IA.

| Pasta | O que tem |
|---|---|

## Combinados

- **Dado real fica fora.** Não cole requisito, código ou bug de cliente ou de projeto real em ferramenta pública.
- **IA é instrumento declarado.** Use à vontade e registre onde usou.
- **Guarde suas saídas.** A partir do encontro 2, o que a IA gerar para você volta no encontro 4, quando a turma avalia o material uns dos outros. Salve cada saída em arquivo, com a data e o nome da ferramenta.
- **Sem acesso, em dupla.** A partir do encontro 2, se a conta ou a instalação falhar, trabalhe com alguém.
