# BUG-107 — Pedido pago com boleto é cancelado sem estorno

Ambiente: homologação · app Android · registrado em 06/11/2026
Funcionalidade: US-02, cancelar pedido pelo app

## Passos para reproduzir

1. Fazer um pedido e pagar com boleto.
2. Aguardar a compensação; o status muda para "Pago".
3. No app, cancelar o pedido, escolhendo um motivo.

## Resultado esperado

O valor é estornado ao cliente (US-02, regra R3).

## Resultado obtido

O status muda para "Cancelado" e o e-mail de confirmação chega, mas nenhum estorno é gerado. O cliente fica sem o dinheiro.

## Observações

- Com cartão de crédito o estorno é solicitado normalmente.
